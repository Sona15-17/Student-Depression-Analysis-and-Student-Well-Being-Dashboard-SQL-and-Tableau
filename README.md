Student Depression Analysis Using SQL & Tableau

## Problem Statement

Student mental health has become a major concern due to academic pressure, financial stress, sleep issues, and lifestyle factors. This project aims to analyze student depression data to identify patterns and understand the key factors contributing to depression among students.
Using SQL for data cleaning and analysis and Tableau for visualization, the project provides insights into how academic pressure, sleep duration, study hours, financial stress, and study satisfaction affect student mental health.

## Steps Followed

- Loaded student depression dataset into SQL Server.
- Checked data quality and handled missing values.
- Standardized fields such as Gender and Depression Status.
- Created Age Group categories (A1, A2, A3) for demographic analysis.
- Performed SQL queries using GROUP BY, COUNT, AVG, and filtering techniques.
- Analyzed relationships between depression and:
  - Academic Pressure
  - Sleep Duration
  - Study Hours
  - Study Satisfaction
  - Financial Stress
- Imported processed data into Tableau.
- Built an interactive dashboard with multiple visualizations.
- Added filters and formatting for better user interaction.
- Generated insights to identify major factors associated with student depression.

## Key Insights

- Students experiencing higher academic pressure show higher levels of depression.
- Lower sleep duration is associated with increased depression rates.
- Financial stress significantly impacts student mental health.
- Students with lower study satisfaction tend to report higher depression levels.
- Certain age groups show higher vulnerability to depression.
- Interactive dashboard helps identify mental health trends quickly and effectively.

- ## Tools Used

- SQL Server (Data Cleaning & Analysis)
- Tableau (Data Visualization & Dashboard Creation)

- ## Project Summary

Analyzed 503 student records using SQL and Tableau to identify factors influencing student depression. Performed data cleaning, transformation, and aggregation using SQL. Developed an interactive Tableau dashboard to visualize academic pressure, sleep duration, financial stress, study satisfaction, and depression trends. Generated actionable insights to understand the relationship between mental health and student lifestyle factors.
